SHOPSCOPE v2 (ES / EN) - Investigacion de mercado para Etsy
=============================================================
ARCHIVOS: server.py, index.html, requirements.txt (los 3 juntos, en la misma carpeta)

ACTUALIZAR EN RENDER (ya tienes el repositorio "shopscope")
1. GitHub > tu repositorio > Add file > Upload files: sube los 3 archivos (sustituyen a los antiguos) > Commit changes.
2. Render redespliega solo (1-3 min). Si no, Manual Deploy > Deploy latest commit.
3. Las claves van SOLO en Render > Environment:
   ETSY_API_KEY = tu keystring     ETSY_SHARED_SECRET = tu shared secret
   (Opcional, para el Asistente con IA) ANTHROPIC_API_KEY = tu clave de Anthropic. Tiene coste por uso; sin ella el asistente usa reglas gratis.
   NUNCA pongas claves en GitHub ni en el chat.

EJECUTAR EN LOCAL
   pip install -r requirements.txt
   (Windows)  set ETSY_API_KEY=...   (Mac/Linux) export ETSY_API_KEY=...
   python server.py   ->  http://127.0.0.1:8000

COACH IA: menu "Coach IA de Etsy". Necesita GEMINI_API_KEY (gratis) o GROQ_API_KEY en Render > Environment.
Su conocimiento esta en la carpeta conocimiento/ (un .md por tema). Para ampliarlo, sube mas archivos .md a esa carpeta de GitHub: la IA los usa solo.
La carpeta debe estar en la raiz del repositorio, junto a server.py.

NOVEDADES v2.1: Mercado (Top tiendas vendedoras, Top articulos mas vendidos [estimado], Top palabras y frases) con filtro de pais/region,
33 paises, graficos (barras, circular, histogramas), fotos con reintento automatico y avatares de tienda.
SI NO VES FOTOS: abre https://TU-WEB.onrender.com/api/imgtest . Si "with_images" es 0, Etsy no esta devolviendo fotos con tu clave y dime que sale.

NOVEDADES v2: idioma ES/EN, filtro de pais del vendedor, fotos con ficha, nota SEO, Category Report, Listings,
AI Listing Helper, Compare Listings, Changes, Traffic Stats, Spotted on Etsy, Tag Report, Mapa de competencia,
Trend Buzz, Tendencias mensuales.
LIMITES: la API de Etsy no da volumen de busquedas, clics ni CTR; no se inventan (puedes anotar las busquedas a mano en Keyword Lists).
